# Sales Case Study

## 📊 Project Overview

This Sales Case Study analyses sales, pricing, quantity sold, profitability, and promotional activity using a daily sales dataset.

The purpose of the project is to explore how changes in selling price relate to sales volume and profitability, with a particular focus on promotional pricing and price elasticity of demand.

The project demonstrates the use of data analysis and visualisation techniques to investigate business questions and present findings in a clear, data-driven format.

---

## 🎯 Project Objectives

The analysis focuses on:

* Calculating daily selling price per unit
* Calculating average unit selling price
* Analysing gross profit and gross profit percentage
* Calculating gross profit per unit
* Comparing normal and promotional pricing
* Selecting promotional periods for analysis
* Calculating price elasticity of demand
* Comparing sales performance during promotional periods
* Identifying trends and patterns within the sales data

---

## 📁 Dataset

The dataset contains daily sales information used to analyse:

## 📌 Key Calculations

The project uses the following calculations:

**Unit Selling Price**

`Sales ÷ Quantity Sold`

**Gross Profit**

`Sales − Cost of Sales`

**Gross Profit %**

`Gross Profit ÷ Sales × 100`

**Gross Profit Per Unit**

`Gross Profit ÷ Quantity Sold`

**Price Elasticity of Demand**

`% Change in Quantity Demanded ÷ % Change in Price`
